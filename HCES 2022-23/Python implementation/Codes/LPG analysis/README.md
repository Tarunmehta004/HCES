# About
Objective -- Identify major determinants of LPG usage in India.
Method -- Fit a random forest on LPG classes using socio-economic data.


# Repo structure
1. `Encodings.txt`: Labels used for missing data in HCES 2022-23.
2. `Extraction.iPYNB`: Notebook file to extract and export relavant information from HCES.
3. `Raw_data.dta`: Output of `Extraction.iPYNB`. Contains the raw data used for classification.
