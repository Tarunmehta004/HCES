## About
Over 37 per cent of the households continue to rely on firewood as a primary source for cooking in India. To improve penetration of clean cooking in the country, it is important to identify geographies and socio-economic groups that continue to rely on firewoods. This repo contains the code and results for such an analysis using raw data from HCES 2022-23 and 2023-24. Some of the themes explored in this analysis include: LPG subsidies, average consumption of firewood and LPG, and share of monthly expenditure spent on purchasing firewood and LPG for cooking.

## Repo structure 
This repo consists of the following files of interest:
1. `TM - LPG analysis 4Apr25.xlsx`: Collates final results of the analysis.
2. `TM - LPG and firewood 2022-23 HCES.iPYNB`: Contains python code for analysis of 2022-23 HCES data.
3. `TM - LPG and firewood 2023-24 HCES.iPYNB`: Contains python code for analysis of 2023-24 HCES data.
4. `TM - potential LPG subsidy schemes 9May25.xlsx`: Collates list of existing central government schemes that can be used to promote LPG consumption.
