## About
With increase in frequency and severity of heatwaves in India, cooling has become a developmental need. HCES asks questions regarding stock and expenditure on certain cooling applicances, including fan, cooler, air conditioner and refrigerator. Currently, the repo contains only one notebook that offers a template to analyse both stock and expenditures. By tweaking the item names, this template can be used for any commodity. 

## Repo structure 
This repo consists of the following files of interest:
1. `TM - Cooling appliances 2023-24 HCES.iPYNB`: Contains python code to analyse stock and expenditure on various cooling appliances.
